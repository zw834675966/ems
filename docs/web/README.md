# Energy Management System (EMS)

A modern Energy Management System frontend built with Vue 3, Vite, Element Plus, and TailwindCSS.

## Features

- **Real-time Monitoring**: Visualize energy data.
- **Device Management**: Configure gateways and devices.
- **Data Analysis**: Historical data and reporting.

## Project Setup

### Install Dependencies

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

### Build

```bash
pnpm build
```
