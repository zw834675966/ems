

# TCP 物联网网关通信协议定义文档

**文档版本**：V1.0
**传输方式**：TCP（长连接）
**适用场景**：网关聚合多个设备数据，上报至服务器
**编码方式**：二进制
**字节序**：Big-Endian（高字节在前）

---

## 1. 总体帧结构定义

### 1.1 帧格式

```
| SOF | VER | FRAME_LEN | DEV_COUNT | DEV_BLOCK... | CRC |
```

---

### 1.2 帧字段定义表

| 序号 | 字段名       | 长度(Byte) | 类型     | 说明                            |
| -- | --------- | -------- | ------ | ----------------------------- |
| 1  | SOF       | 2        | 固定     | 帧头，固定为 `0xAA55`               |
| 2  | VER       | 1        | UInt8  | 协议版本号，当前为 `0x01`              |
| 3  | FRAME_LEN | 2        | UInt16 | 帧长度（从 VER 到 CRC 前，不含 SOF、CRC） |
| 4  | DEV_COUNT | 1        | UInt8  | 本帧包含的设备数量                     |
| 5  | DEV_BLOCK | N        | 结构体    | 设备数据块（重复 DEV_COUNT 次）         |
| 6  | CRC       | 2        | UInt16 | CRC16 校验值                     |

---

## 2. CRC 校验规则

| 项目   | 说明                     |
| ---- | ---------------------- |
| 算法   | CRC16-Modbus           |
| 多项式  | 0xA001                 |
| 初始值  | 0xFFFF                 |
| 计算范围 | 从 VER 字段开始，到 CRC 前一个字节 |
| 校验失败 | 丢弃整帧                   |

---

## 3. 设备数据块（DEV_BLOCK）定义

### 3.1 设备块结构

```
| DEV_ID | DEV_TYPE | DEV_LEN | DEV_PAYLOAD |
```

---

### 3.2 设备块字段定义表

| 序号 | 字段名         | 长度(Byte) | 类型     | 说明      |
| -- | ----------- | -------- | ------ | ------- |
| 1  | DEV_ID      | 2        | UInt16 | 设备唯一编号  |
| 2  | DEV_TYPE    | 1        | UInt8  | 设备类型    |
| 3  | DEV_LEN     | 2        | UInt16 | 本设备数据长度 |
| 4  | DEV_PAYLOAD | N        | Byte[] | 设备参数数据  |

---

## 4. 设备类型定义表（DEV_TYPE）

| DEV_TYPE | 设备类型  | 说明          |
| -------- | ----- | ----------- |
| 0x01     | 电参量设备 | 电压/电流/功率/电量 |
| 0x02     | 温湿度设备 | 温度、湿度       |
| 0x03     | 开关量设备 | DI / DO     |
| 0xFF     | 自定义   | 厂商自定义       |

---

## 5. 设备参数数据定义（TLV 推荐方案）

### 5.1 参数结构（TLV）

```
| TAG | LEN | VALUE |
```

---

### 5.2 参数字段定义

| 字段    | 长度 | 类型     | 说明       |
| ----- | -- | ------ | -------- |
| TAG   | 1B | UInt8  | 参数标识     |
| LEN   | 1B | UInt8  | VALUE 长度 |
| VALUE | N  | Byte[] | 参数值      |

---

### 5.3 电参量设备参数 TAG 定义表（DEV_TYPE = 0x01）

| TAG  | 参数  | VALUE 类型 | 单位       | 说明               |
| ---- | --- | -------- | -------- | ---------------- |
| 0x01 | 电压  | UInt16   | 0.1 V    | 380.2V → 3802    |
| 0x02 | 电流  | UInt16   | 0.1 A    | 198.4A → 1984    |
| 0x03 | 功率  | Int32    | 0.1 kW   | 119.6kW → 1196   |
| 0x04 | 电量  | UInt32   | 0.01 kWh | 3561.23 → 356123 |
| 0x05 | 状态字 | UInt8    | Bit      | 运行/告警            |

---

### 5.4 状态字（TAG=0x05）位定义

| Bit    | 含义   |
| ------ | ---- |
| bit0   | 运行状态 |
| bit1   | 告警   |
| bit2   | 通信异常 |
| bit3–7 | 保留   |

---

## 7. 异常处理规则

| 场景      | 处理方式        |
| ------- | ----------- |
| SOF 不匹配 | 丢弃字节，继续查找帧头 |
| 长度非法    | 丢弃整帧        |
| CRC 错误  | 丢弃整帧        |
| 未识别 TAG | 跳过（根据 LEN）  |

---

## 8. 协议扩展与兼容性

* 新增参数：新增 TAG，不影响旧解析
* 新增设备类型：新增 DEV_TYPE
* 协议升级：提升 VER 字段
* 保留字段：必须填 0

---

## 9. 设计结论

> 本协议采用 **“帧头 + 长度 + 设备块 + CRC + TLV 参数”** 结构，
> 兼顾 **性能、扩展性、稳定性**，适用于工业物联网长期运行场景。
